# Machine Learning

Python projects made for the Machine Learning course during the fourth semester (2024/2025) at Warsaw University of Technology.

---

## Project 1: Diabetes Prediction

This project focuses on predicting whether a person is at risk of having diabetes using a dataset containing health and demographic data of 100,000 individuals. The goal was to create a machine learning model that could contribute to medical research and assist healthcare professionals in early diagnosis, allowing for timely intervention and lifestyle modifications.

The project was carried out end-to-end, including data preprocessing, feature selection, model training, evaluation, and interpretation. Various machine learning techniques were applied, including logistic regression, random forest, gradient boosting, and ensemble methods, and model performance was assessed using standard metrics and visualisations. The results were validated at every stage by an independent team to ensure reliability and accuracy.

The project was implemented in Python using libraries such as Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, and SHAP.

## Project 2: Flower Diversity Clustering

This project focuses on clustering flower images based on visual similarity. The goal is to assist in organising large image collections, support pre-analysis, and potentially be used in plant identification applications, such as automatically grouping newly uploaded flower images into corresponding folders.

The project was carried out end-to-end, including feature extraction, dimensionality reduction, clustering, evaluation, and visualisation. Various clustering techniques were applied, including KMeans, Agglomerative Clustering, Spectral Clustering, and Gaussian Mixture Models, and results were assessed using standard metrics and visualisations. The results were validated at every stage by an independent team to ensure reliability and accuracy.

The project was implemented in Python using libraries such as NumPy, Pandas, Scikit-learn, Matplotlib, and PyTorch.

Also available on [Kaggle](https://www.kaggle.com/code/kasiaskoczylas/floral-diversity-clustering).
